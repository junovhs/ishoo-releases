# Ishoo

Ishoo lets your AI agents run your project like a good engineering team. This repository holds Ishoo's release builds and installer.

## Install (Windows)

In PowerShell:

```powershell
irm https://raw.githubusercontent.com/junovhs/ishoo-releases/main/install.ps1 | iex
```

Then run `ishoo`. The window walks you through picking a project folder and connecting the agent you already use (Claude Code, Codex, or anything that speaks MCP). Your project's records stay on your computer unless you choose to sync them.
